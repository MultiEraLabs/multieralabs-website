PLATFORM SOFTWARE

Atari

Software, test planning and curated resources for Atari 8-bit systems and ST/TT/Falcon.

Status

Atari is prepared as a future platform family.

No Atari browser or MultiEra program test is currently documented as PASS, so nothing here is presented as already supported.

Platform Scope

400/800XL/XEST/TT/Falcon

MultiEra Labs treats Atari as a combined family spanning the 8-bit machines and the later 16/32-bit ST line.

Test Plan

Planned work separates the 8-bit and ST environments: web/browser capability, networking, file transfer, and suitability of our website editions.

A PASS is assigned only after testing a concrete system.

MultiEra Programs

No Atari build is currently released as supported.

  • Atari 8-bit and ST are not treated as one interchangeable software platform
  • Programs will be documented by target system and version
  • Downloads appear only after a working build and test
  • Future program pages will link directly to the appropriate Atari versions
PLANNED

Test Areas

  • Atari 8-bit: browser/network options and file transfer
  • ST/TT/Falcon: TOS environments, networking and web access
  • Disk images and transfer between modern systems and Atari
  • Compatibility with Legacy and 8-Bit website editions
