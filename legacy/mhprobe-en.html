MULTIERA HARDWARE PROBE 1.0
DOS EDITION 1.0 - RELEASED

The program reports hardware details without changing hardware configuration. A REPORT.TXT file can be saved using menu option 9.

Features:
CPU and FPU, RAM / XMS / HMA, BIOS and SMBIOS / DMI, PCI BIOS, ISA / PnP BIOS, MCA / Micro Channel, ports, diagnostics and hardware ID databases.

System: DOS, x86 386 or newer. No installer required.
Package: 1.44 MB FAT12 floppy image with EXE, DAT, README, CHANGES and LICENSE.
Tests in the included README: MS-DOS 6.22 using an 86Box IBM PS/2 Model 70 profile, and a Windows 98 DOS environment.
