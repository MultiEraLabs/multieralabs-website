MULTIERA LEGACY BROWSER
Status: In Development

Der MultiEra Legacy Browser entsteht für Computer, die mit dem heutigen Web kaum noch etwas anfangen können. Er soll klein, schnell und bewusst einfach bleiben.

Geplante Schwerpunkte:
- klassisches HTTP
- einfaches HTML
- Text und Links
- GIF/JPEG und je nach Plattform weitere Bildformate
- Downloads
- niedrige Hardware-Anforderungen

Der Browser soll keine moderne Chromium-Engine auf alte Hardware pressen. Er soll vielmehr genau die Art von Web bedienen, für die auch die MultiEra-Legacy-Seite entwickelt wird.

Erstes wichtiges Ziel: Win16 / Windows 3.1.
Weitere Plattformen werden nach den ersten technischen Prototypen bewertet.
