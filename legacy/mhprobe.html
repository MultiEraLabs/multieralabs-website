MULTIERA HARDWARE PROBE 1.0
DOS EDITION 1.0 - CLASSIC

Das Programm zeigt Hardwareinformationen an, ohne Hardwareeinstellungen zu verändern. Eine Berichtdatei REPORT.TXT kann über Menüpunkt 9 gespeichert werden.

Funktionen:
CPU und FPU, RAM / XMS / HMA, BIOS und SMBIOS / DMI, PCI-BIOS, ISA / PnP-BIOS, MCA / Micro Channel, Ports, Diagnosen und ID-Datenbanken.

System: DOS, x86 ab 386. Keine Installation erforderlich.
Classic Edition: Schlanke Oberfläche für ältere DOS-PCs; eigenes Programm-ZIP ohne Bootdiskette wird vorbereitet.
Tests laut Release-README: MS-DOS 6.22 im IBM-PS/2-Model-70-Profil in 86Box; Windows-98-DOS-Umgebung.
