IN DEVELOPMENT

Inventory, understand and document hardware — without modifying the system itself.

Hardware Probe is designed for inventory, diagnostics and lab documentation. It reads information and reports anomalies, but never performs automatic repairs.

DOSWindowsREAD-ONLYTXT REPORTS

Use cases

  • inventory of vintage PCs
  • documentation before upgrades or driver work
  • troubleshooting and support
  • comparable TXT reports for the MultiEra Hardware Lab

Current development status

The DOS branch is already under active development. The current DEV build detects CPU/CPUID information and XMS memory data and emits diagnostic notices.

Internal development track: DOS DEV 0.03.

Target platforms

DOSWin 3.x–XPmore systems later

The current focus is DOS and classic Windows. Additional platforms will only be listed as supported after our own tests.

Analysis areas

  • CPU and FPU
  • conventional, XMS/extended and other system memory
  • motherboard and bus systems
  • ISA, PCI, Micro Channel, NuBus/Zorro in later ports
  • ports and attached hardware
  • errors, warnings and explanatory notices

Fixed safety rule

Hardware Probe remains a diagnostic tool.

  • no automatic repairs
  • no Registry/INI changes
  • no CONFIG.SYS/AUTOEXEC.BAT changes
  • no driver installation
  • no BIOS/CMOS changes
READ ONLY

Reports

Output is intended to be readable on screen and saveable as TXT. This makes it possible to document real machines and compare later changes.

  • hardware overview
  • diagnostic summary
  • errors / warnings / notices
  • guidance for manual follow-up checks

Download status

No public version yet.

Development builds will only be released once detection and reports have been verified reliably on suitable target systems.
