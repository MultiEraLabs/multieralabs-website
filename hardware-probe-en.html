CPU and memory

  • 386/486 detection and CPUID where supported
  • FPU identification
  • conventional memory, XMS and HMA
  • BIOS signatures and DMI/SMBIOS if available

Buses and interfaces

  • PCI BIOS, device IDs, classes and IRQs
  • ISA / PnP BIOS resources where supported
  • IBM PS/2 Micro Channel / MCA and POS data
  • COM, LPT and classic PC hardware

Diagnostics and databases

  • warnings and diagnostic notices
  • MCA, PCI, CPU, BIOS and PnP databases
  • paged on-screen output
  • complete REPORT.TXT report

Install and run

Once a new DOS package is released, MHPROBE.EXE and its .DAT files will reside in the same directory. Start using MHPROBE; menu option 9 opens report saving.

Safety and testing

Read-only hardware configuration: no automatic repairs, PCI BAR writes, CMOS changes, PnP node changes or MCA reconfiguration. Only the explicitly requested TXT report is written to disk.

The included release README documents testing on MS-DOS 6.22 in an 86Box IBM PS/2 Model 70 setup and in a Windows 98 DOS environment. This does not guarantee operation on every physical machine.

Previous floppy images are no longer offered for download.
